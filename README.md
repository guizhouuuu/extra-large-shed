# 超大屋子 / Extra Large Shed 1.1.0


[下载安装包 v1.1.0](https://github.com/guizhouuuu/extra-large-shed/releases/tag/v1.1.0)。在发布页的 Assets 下载 Mod ZIP。

在罗宾的原版建筑菜单中，把**已建成的大屋子（Big Shed）**升级为“超大屋子”。名称、建造介绍及SMAPI名称均为中文。

| 项目 | 数值 |
| --- | --- |
| 金币 | 25,000 |
| 木头 | 999 |
| 石头 | 500 |
| 施工 | 2个原版施工日 |
| 农场占地 | 7×3，与大屋子一致 |
| 室内可用地面 | 24×17＝408格，原版17×12＝204格的两倍 |
| 改色 | 原版墙体、屋顶、装饰三通道 |

长宽同时扩大，组成一间完整房间，入口在底边中央两格中的左格。地面尺寸不计外围墙与门洞；完整地图26×22格。1.1.0修复旧版横向拼接布局、室内残留转角与中文回退文本。

需要PC版Stardew Valley **1.6.15 build 24356**、SMAPI **4.5.2**。单个SMAPI Mod，无Content Patcher或Harmony依赖。

## 安装与使用

1. 保存并完全退出游戏。解压安装ZIP，把ExtraLargeShed文件夹放入游戏Mods目录；更新时覆盖同名Mod，不要并存两个版本。
2. 使用SMAPI启动游戏。先建小屋，按原版流程升级为大屋子并等完工。
3. 在罗宾的建筑菜单选择“超大屋子”，选中已建成的大屋子。费用、材料和施工由原版界面处理，Mod不会额外扣款。
4. 等待两个原版施工日。节日及罗宾工作安排遵循游戏规则。
5. 室内扩大为24×17格，门口居中。原有地板、壁纸样式延伸到新区。
6. 搬动、拆除及墙体/屋顶/装饰改色沿用罗宾原版菜单。

## 从1.0.0更新与物品保留

更新前备份存档。沿用相同建筑ID、地图资产ID及原版Shed实例，已有建筑无需拆除重建或重新付款。

在新边界内且不挡新门口的现有摆设保留原坐标。旧版右侧超出新边界的物体、家具及壁画，在首次加载或日开始时优先安置到最近的可容纳位置；空间不足时将**原物品实例**放入室内“超大屋子搬迁回收箱”，不复制成空物品。家具旋转、箱子内容、机器heldObject、假人穿着及modData随原实例保留。回收箱每个最多装36件，支持多个箱子，门口接近格保留通行。

迁移成功后在建筑modData记录LayoutVersion=2，后续读档不会重复整理。若发生异常，恢复原有物品引用和位置、记录错误并提示不要保存；请先保留现场日志排查。普通原版大屋子升级时也进行同一边界检查。

这不是自动整理功能：原有合法重叠（如地毯上的家具）保留，之后玩家自行摆放不被持续干预。不保证迁移其他Mod插入的terrainFeatures或改变室内规则的特殊家具。游戏内保存、加载和实际使用仍需验收。

## 构建

需要.NET SDK 8.0.2xx或更新版本，目标net6.0，Pathoschild.Stardew.ModBuildConfig固定4.4.0。

```powershell
dotnet build .\ExtraLargeShed.csproj -c Release '-p:GamePath=C:\path\to\Stardew Valley'
.\tools\build.ps1 -GamePath 'C:\path\to\Stardew Valley' -RunSmokeTests
```

执行无图形验证需要.NET 6 runtime。默认不自动部署，安装ZIP输出到工程相邻packages目录。包内无游戏或SMAPI程序集，无原版XNB或tilesheet；室内在运行时从本机Maps/Shed2独立生成。

## 贴图与兼容范围

外观沿用1.0.0的112×128像素贴图、硬透明与64色及精确RGB改色遮罩。外观由image_gen生成参考原图，再由tools/pack-art.py打包；原图及提示词保留在art目录。本次重做的是地图拼接规则，未重新生成外观。

明确支持原版Big Shed的7×3占地、Shed2的19×17地图模板及三通道涂漆。其他Mod若改变模板尺寸会明确报错；即使尺寸相同但布局被替换，也不承诺兼容。单人优先，多人及大改室内的组合未经验证。

## 卸载

已有超大屋子时不要直接删除Mod。先备份存档，等施工完成，把屋内物品、家具、机器及搬迁回收箱全部搬出，通过罗宾拆除超大屋子，保存退出后再删除Mod文件夹。未升级任何建筑时可以保存退出后直接移除。
